## Transport Contract

1. Keep the current API first, then the existing official raw URL, then at
   most one retry of raw: three explicit download attempts total.
2. Preserve the 30-second per-open timeout; sleep 1 then 2 seconds only when
   another attempt is eligible. This is not a global wall-clock or wire-
   request bound; urllib may follow redirects.
3. API transport failure permits fallback. Raw retry is limited to transport/
   read failures, HTTP 408/429 or 5xx; permanent raw HTTP errors stop early.
4. Verify the unchanged SHA-256 immediately after every complete response.
   A mismatch is terminal, never a reason to try a different source.
5. Preserve TLS verification, exact schema commit/URLs/hash/validator and all
   structural, lock-coverage, size and secret gates. No cached/unverified
   schema, structural-only acceptance, credentials or dependency changes.
6. Validator rejection, timeout or local-file failure remains terminal.
7. Transport diagnostics contain only endpoint labels, attempt numbers, fixed
   error categories and numeric HTTP status. No URL, body, headers, exception
   message, private path or secret value.
